Учебный проект: База данных, хранящая список студентов

Формат хранения: указатели на объекты структуры Student хранятся в В-дереве и списке. Для кадой группы или списка есть свое дерво.
Базой данных управляет класс DataManager.

Поддерживаемые команды: (команды SELECT и DELETE могут искать данные по двум или одному признаку)



SELECT [name = строка] [, group = число[-число]] [, rating = число[-число]] 

INSERT name = строка, group = число, rating = число

REMOVE [name = строка] [, group = число[-число]] [, rating = число[-число]]

PRINT выводит всю базу данных 

Все результаты отображаются в файл output.txt
